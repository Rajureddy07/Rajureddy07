## Profile

I'm a final-year B.E. Computer Science & Engineering (Data Science) student at Vivekananda College of Engineering and Technology (VCET), Puttur. I learn by building end-to-end projects—from data preparation and SQL queries to interactive dashboards, document processing, and application workflows.

**Areas I work in**
- Data analytics: Python, Pandas, SQL, PostgreSQL, Streamlit, Plotly
- Applied AI: OCR, image preprocessing, fuzzy matching, structured extraction
- Application development: FastAPI, Flask, React, TypeScript, Docker
